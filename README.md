🎓 Smart Student Study Planner – Agentic AI

📌 Project Overview

The Smart Student Study Planner is an Agentic AI-based application designed to help students organize their studies through personalized, subject-specific study plans.

The system helps students manage study time, prioritize subjects, track completed sessions and monitor their learning progress.

🎯 Problem Statement

Students often struggle with time management, subject prioritization and maintaining consistent study schedules. Traditional study planners provide limited personalization and do not dynamically adapt to student progress.

💡 Proposed Solution

An intelligent study planner that uses multiple AI agents to generate personalized study schedules, prioritize learning tasks and track student progress.

✨ Key Features

- Subject-specific study plan generation.
- Personalized study-hour allocation.
- Intelligent subject prioritization.
- AI-powered planning and analysis.
- Study session completion tracking.
- Confidence-based progress monitoring.
- Automatic progress calculation.
- Dynamic study schedule management.

🤖 Agentic AI Architecture

The project uses specialized agents to support the planning process:

1. Planning Agent: Helps generate subject-specific study plans.
2. Analysis Agent: Analyzes study-related information and progress.
3. Priority Engine: Helps prioritize subjects and study tasks.

🛠️ Technologies Used

- Programming Language: Python
- Backend: FastAPI
- Database: SQLite
- ORM: SQLAlchemy
- Frontend: Project frontend interface
- AI Architecture: Multi-Agent System

⚙️ How to Run the Project

1. Clone the repository

git clone https://github.com/eng23am0089-cpu/Smart-Student-Study-Planner.git

2. Navigate to the project

cd Smart-Student-Study-Planner

3. Create a virtual environment

python -m venv venv

4. Activate the environment (Windows)

venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Start the backend

uvicorn main:app --reload

7. Open API documentation

Visit:

http://127.0.0.1:8000/docs
